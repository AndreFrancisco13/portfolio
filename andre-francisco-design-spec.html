01 — Conceito e Personalidade

Nome do projeto: Portfolio de André Francisco — fotógrafo e designer baseado em Portugal.

Conceito central: "The Still Studio" — um portfolio que evoca um estúdio de impressão analógico, silencioso e iluminado a luz natural. Tudo comunica tempo, intenção e matéria.

Personalidade: Calmo, artesanal, vintage, confiante. Sem urgência digital. Cada detalhe comunica que o criador experimenta o tempo de forma diferente da internet.

Influências visuais: Capas da Vogue dos anos 40, revistas editoriais tipográficas, tecnologia retro dos anos 80 (computadores e walkmans), câmaras analógicas e pranchas de contacto fotográfico.

Cursor: cursor: crosshair — reforça a linguagem fotográfica/de estúdio.

Regra de cor: Nunca usar branco puro (#FFFFFF) nem preto puro (#000000). Todos os tons têm calor amarelado. O terracota é usado apenas em destaques — links hover, eyebrows, sombras de botões no hover.

04 — Efeitos Globais

Grain Overlay (textura de papel)

Aplicado via body::before com position: fixed; inset: 0; z-index: 9999; pointer-events: none; opacity: 0.045. Usa um SVG inline com feTurbulence (fractalNoise, baseFrequency 0.9, 4 octaves) como background-image com 200×200px de tile. Cria uma textura subtil de grão de papel analógico em toda a página.

Scrollbar personalizada

Largura 6px, thumb em warm-gray, sem border-radius (ângulos retos, estilo analógico), track em parchment.

Animações de entrada

Dois keyframes: fadeUp (opacity 0→1 + translateY 24px→0) e fadeIn (opacity 0→1). Hero esquerdo aparece em 1s com delay 0.2s. Hero direito em 1.4s com delay 0.5s. Cards aparecem em escalonamento: delay 0.1s, 0.25s, 0.4s, 0.55s, 0.7s, 0.85s.

09 — Prompt Completo para Replicação

Copia e cola este prompt numa outra IA:

Cria um portfolio HTML/CSS de página única para André Francisco, fotógrafo e designer português. Usa apenas HTML, CSS e JS vanilla — tudo num único ficheiro .html.

IDENTIDADE: Vintage analógico. Tom calmo, artesanal, sem urgência digital. Inspirado em revistas editoriais dos anos 40, câmaras analógicas e pranchas de contacto fotográfico.

FONTES (Google Fonts): Courier Prime (todos os títulos e corpo) + Playfair Display (apenas para a citação na secção About). Nunca usar Inter, Roboto ou Arial.

PALETA: --parchment:#F2EBD9 (fundo), --parchment-dark:#E8DEC8 (fundos secundários), --ink:#1E1810 (texto/bordas), --ink-soft:#3A2F22, --terracotta:#8B4A2F (acento/hover), --warm-gray:#C4B49A (bordas leves), --sepia:#7A6145 (texto secundário), --dust:#A89880 (labels). Nunca usar branco puro nem preto puro.

EFEITOS GLOBAIS: Grain overlay via body::before com SVG feTurbulence (fractalNoise, baseFrequency 0.9, 4 octaves), opacity 0.045, fixed, z-index 9999, pointer-events none. Cursor crosshair. Scrollbar personalizada 6px, sem border-radius.

NAV (fixed): Logo "André Francisco" (Courier Prime 700, "Francisco" em terracota) esquerda. Direita: links TRABALHO · SOBRE · CONTACTO (Courier Prime 0.7rem bold uppercase letter-spacing 0.2em, hover terracota) + botão "FALAR COMIGO" com border 2px ink, box-shadow 3px 3px 0 ink, hover translate(-2px,-2px) + shadow 5px 5px 0 terracota.

HERO (grid 1fr 1fr, 100vh): Esquerda: overline "— Fotógrafo & Designer" (terracota, ::before com "— ") + H1 "André / Francisco" (Francisco em itálico terracota, Courier Prime clamp 3.5rem→7rem 700) + bio + link "Ver trabalho ↓" com border-bottom. Direita: fundo parchment-dark, "AF" decorativo gigante (Courier Prime clamp 10–22rem, italic, opacity 0.55, centrado) + tags de ferramentas no rodapé.

SECTION DIVIDER: Entre cada secção. Flex, altura 52px, border-top e bottom 1px warm-gray. Label uppercase dust esquerda · linha flex · texto warm-gray direita.

WORK (grid 3 colunas, gap 1.8rem): 6 project cards. Cada card: border 2px ink, box-shadow 4px 4px 0 ink, hover translate(-3px,-3px) + shadow 7px 7px 0 terracota. Estrutura: imagem topo (4/3, fundo bege, número romano Courier Prime centrado, border-bottom 2px ink) + corpo com [season label terracota] + [header: título Courier Prime 1.15rem 700 + 2 botões 30×30px border 1.5px ink] + descrição sépia + tags (border 1.5px ink-soft, hover terracota).

ABOUT (grid 1fr 1fr): Esquerda: título + 2 parágrafos bio + grid 2×2 de stats (12+, 80+, 3, ∞) com label em dust uppercase. Direita: fundo parchment-dark, citação em Playfair Display 2rem italic + atribuição "— André Francisco".

CONTACT (flex space-between): Eyebrow terracota com ::before "— " + título grande + email com border-bottom + hover terracota. Direita: 4 links sociais em coluna uppercase.

FOOTER: Copyright esquerda + "Feito com lentidão" direita (Playfair italic, warm-gray).

ANIMAÇÕES: fadeUp (opacity 0→1 + translateY 24px→0) e fadeIn (opacity 0→1). Cards com animation-delay escalonado: 0.1s, 0.25s, 0.4s, 0.55s, 0.7s, 0.85s.
